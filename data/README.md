# Sample corpus

This directory contains the compact JSON corpus used by the retrieval service:

- `restaurants.json`: 20 restaurant records
- `reviews.json`: 10 restaurant-review records
- `recipes.json`: 109 recipe records with generated image descriptions

The application does not require the original notebooks, source archive, or
recipe image files. Alternative datasets can be supplied with
`RESTAURANT_DATA_PATH`, `REVIEW_DATA_PATH`, and `RECIPE_DATA_PATH`.

application was prepared. Confirm that you have the necessary redistribution
